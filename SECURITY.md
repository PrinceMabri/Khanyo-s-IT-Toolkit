# Security Policy

## Supported Versions

The project currently supports the latest released version on the `main` branch.

## Reporting a Vulnerability

Please report suspected security issues privately through GitHub by opening a security advisory or by contacting the maintainer through the repository's security contact options.

Please do not open a public issue for a security vulnerability until a fix has been released or the issue has been explicitly triaged as non-sensitive.

## Responsible Disclosure

We ask reporters to:

- provide a clear description of the vulnerability and affected behavior
- include steps to reproduce the issue when possible
- avoid exposing sensitive data or credentials in reports
- allow a reasonable amount of time to investigate and remediate the issue

We will review reported issues promptly and coordinate a fix and disclosure timeline.
